## 4. 安装

### 4.1 全新安装（推荐）

```bash
dsh plugin --profile desktop add link:C:/Users/Ren/Documents/deepseek-harness/插件工作区/dsh-member-manager
# 重启 DSH 后确认：
#   GET http://127.0.0.1:<port>/api/dsh-member-manager/health   → {ok:true,...}
#   GET http://127.0.0.1:<port>/api/dsh-member-manager/state    → 含 company 摘要
```

### 4.2 从旧包 `dsh-plugin-member-manager` 切换

**自动（脚本，默认 dry-run）：**

```bash
# 先看计划（不写盘）
node scripts/switch-to-dsh-member-manager.mjs
# 确认后执行；脚本会备份 profile 的 package.json / cordis.yml 到 ~/.dsh/backups/
node scripts/switch-to-dsh-member-manager.mjs --apply
# 重启 DSH
```

脚本改 profile 三处：`dependencies`（旧名→`dsh-member-manager: link:<本目录>`）、`dsh.profile.bundles`（旧名→新名）、`cordis.yml`（`id/name` 旧名→新名），并重建 `node_modules/dsh-member-manager` 链接。

**手工等价步骤：**

1. 编辑 `~/.dsh/profiles/desktop/package.json`：`dependencies` 删 `"dsh-plugin-member-manager"`，加 `"dsh-member-manager": "link:<本目录绝对路径>"`；`dsh.profile.bundles` 里旧名换成新名。
2. 编辑 `~/.dsh/profiles/desktop/cordis.yml`：把 `- id: dsh-plugin-member-manager / name: dsh-plugin-member-manager` 改成新名。
3. 重建 `node_modules/dsh-member-manager` 链接（Windows：`mklink /J "%USERPROFILE%\.dsh\profiles\desktop\node_modules\dsh-member-manager" "<本目录>"`）。
4. 重启 DSH。
5. 打开「成员管理」面板确认名册数据仍在（数据目录不变：`~/.dsh/storages/member-manager/`）。

### 4.3 回滚

```bash
node scripts/rollback-to-dsh-plugin-member-manager.mjs            # dry-run
node scripts/rollback-to-dsh-plugin-member-manager.mjs --apply    # 写回旧名
# 旧插件目录默认 ~/Documents/deepseek-harness/default-workspace/dsh-plugin-member-manager
# 可用 --old-target 指定；重启 DSH 后生效
```

回滚只改 profile 挂载，不删 0.3.0 数据（`company.json` 是新增文件，旧版忽略即可）。
