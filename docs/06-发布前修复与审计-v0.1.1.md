## 一、本次修复的 Bug

### 1. 主面板内容溢出无滚动条（用户反馈）✅ 已修复
文件：`lib/client.js` · 样式 `S.wrap`

**根因**：面板根容器 `S.wrap` 只有 `padding/font/maxWidth`，没有 `overflow` 也没有高度约束。当成员/小组很多时内容直接顶出宿主容器，宿主区域固定高度且不滚动 ⇒ 内容被剪裁、无滚动条、后面的内容看/点不到。

**修复**：给根容器补上「填充 + 自身滚动」的组合：
```js
wrap: {
  ...,
  boxSizing: "border-box",
  minWidth: 0,
  minHeight: 0,
  height: "100%",
  overflowY: "auto",
}
```
- 宿主给了固定高度 ⇒ `height:100%` 让它撑满并成为自己的滚动容器，滚动条出现；
- 宿主不限制高度（如设置页列表里自然排版）⇒ `height:100%` 退化为 auto，内容照常长高交给页面滚动，**不产生回归**。
- `box-sizing` + `minWidth/minHeight:0` 保证在 flex/grid 布局里不被挤压。
- 面板的三个 return 分支（错误态 / 加载占位 / 正常态）都走 `S.wrap`，行为一致。

> 补充：技能弹层 `SkillPicker` 本身已有 `maxHeight:80vh + overflowY:auto`，不受影响。
