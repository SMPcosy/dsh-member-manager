## 3. 次要问题（P2/P3，含文件:行号与修复建议）

### 3.1 P2 · `createDepartment` 的 `appliedBy` 硬编码为 `"owner"`

- 证据：`src/shared/company-org.mjs:665` 的签名 `createDepartment(company, { id, name, ..., preset })` 没有
  `appliedBy`/`opts` 参数；`:687-689` 恒传 `applyPresetToDepartment(c, id, preset, { appliedBy: "owner" })`。
- 契约：§4 括号写「appliedBy 由调用方传，缺省 "owner"」（docs/24:184 附近）。
- 影响：无运行时缺陷（当前没有需要非 owner 来源的调用方；CLI 走 `updateDepartment`/`applyPresetToDepartment` 自传 `"cli"`）。
  属契约表述与接口面的轻微不一致。
- 建议（二选一，交 Lead 裁决）：① 契约改为「`createDepartment` 固定 `appliedBy:"owner"`，仅 `applyDepartmentPreset`
  接受来源」，并把 CLI 的 `"cli"` 来源写进 §7 已有文案即可；② 给 `createDepartment` 增加可选 `opts.appliedBy`。

### 3.2 P2 · `applyPresetToDepartment` 忽略显式 `ref.version`，落库永远快照注册表当前版本

- 证据：`src/shared/company-presets.mjs:243` 写入 `version: checked.preset.version`（注册表版本），
  而 `normalizePresetRef` 在 `:204-206` 明确保留调用方显式传入的 `version`。
- 影响：若调用方传 `{id:"game-dev", version:1}` 而注册表已升到 v2，`department.preset.version` 会被写成 2，
  从而 `resolveDepartmentPreset` 的 `outdated`（§3.2 定义为 `version !== currentVersion`）永远为 `false`。
  当前注册表仅 v1、无任何调用方传显式 version，因此**无可见影响**；但契约 §3.1 说 normalize 保留显式 version，
  与 apply 的忽略行为存在口径差。
- 建议：在 `:243` 前用 `normalizePresetRef(presetId)?.version ?? checked.preset.version` 尊重显式版本；
  或若设计意图就是「落库总是当前注册表版本」，在 docs/24 §3.1 注明「apply 忽略显式 version」，并删掉
  normalizePresetRef 的显式版本保留分支（避免误导）。

### 3.3 P3 · CLI 对损坏的 store 误报「部门不存在」

- 证据：`scripts/apply-preset.mjs:132-138` 直接使用 `store.load()` 结果；损坏的 `company.json` 被

1. **strong(2 分) > weak(1 分)**：`title`/`displayName` 命中优先于 `duties`/`skills` 命中（如客户端 `title` 含「客户端」

3. **每人一槽**：同一员工不会被多个槽位重复分配（`used` 集合实装于 `company-presets.mjs:314,321-331`）。
4. **M 槽 manager 优先**：`director` 槽在 score 并列时优先 `role === "manager"` 的候选（`:287-291`）；P 槽不启用该优先。
5. **槽位 channel 对应 level rank 降序**：从员工 `channels` 中取与槽位同 channel 的 level，数字大者优先；

6. **code 升序、无 code 最后**：`E0016 < E0017 < …`；无 code 员工排在所有有 code 的后面（`:295-301`）。
7. **无候选 → `null`**；**确定性**：同一输入重复 5 次输出一致；`roles` 声明顺序即分配顺序。
8. **真实数据副本验证**：对 23 人真实 company 副本套用/清除若干次，`apply`/`clear` 均为**纯函数**（不改入参），
